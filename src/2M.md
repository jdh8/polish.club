# Muiderberg 2M

Muiderberg shows exactly 5 cards in the bid major and a side minor suit.
[Multi 2♦](2D.md) already takes care of 6+ cards.  I recommend response
structure combining Meckstroth and transfer advances.

| 2M - | |
|------|-|
| 2♠!  | NAT NF
| 2NT! | INV+, ask for the minor suit
| 3♣!  | P/C

| 2♥ - | |
|-----|-|
| 3♦! | INV+, 3+♥

| 2♠ - | |
|-----|-|
| 3♦! | TRF: (FG, 5+♥) or (INV, 6+♥)
| 3♥! | INV+, 3+♠

| 2M - 2NT - | |
|------|----------|
| 3♣   | MIN, 4+♣ |
| 3♦   | MIN, 4+♦ |
| 3♥!  | MAX, 4=♣ |
| 3♠!  | MAX, 4=♦ |
| 3NT! | MAX, 5+♦ |
| 4♣   | MAX, 5+♣ |
